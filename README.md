# אמון נדל״ן – אתר / דף נחיתה

דף נחיתה בעברית (RTL) לחברת שיווק נדל״ן (יהודה כהן וישראל מזרחי), עם התמחות ברובע הבינלאומי בלוד.
העיצוב בנוי בהשראת המבנה של towers-tlv.com, והתוכן לפי מסמך האפיון.

- `index.html` – הדף עצמו. להעלאה לאחסון: מעלים את `index.html` ואת התיקייה `assets/`.
- `landing-standalone.html` – אותו דף כקובץ יחיד שהתמונות מוטמעות בו (לתצוגה מקדימה או לשליחה).

## עדכון תוכן
בתחתית `index.html` יש מערכי נתונים שבהם מוסיפים פרויקטים ונכסים בלי לגעת בעיצוב:
- `PROJECTS` – פרויקטים: כרטיס, חלון פרטים, נקודה במפה ואפשרות בטפסים.
- `FEATURED` – נכסים נבחרים לפי קטגוריה.
- `REGIONS` – כפתורי הסינון לפי אזור.
- `STEPS` – שלבי תהליך העבודה.
